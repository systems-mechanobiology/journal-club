# Cross-paper synthesis

This folder holds reviewed insights that emerge from paper discussions and journal club sessions. No group conclusions have been recorded yet.

Create a focused Markdown document when a comparison has enough evidence to be useful. Link the relevant catalog entries and original discussion comments.

Suggested structure:

1. Question and scope
2. Papers compared
3. Shared findings and differences
4. Evidence supporting each interpretation
5. Counterexamples and unresolved disagreements
6. Implications for study design
7. Remaining questions

Useful future comparisons include longitudinal evidence versus cross-sectional evidence, predictive performance versus clinical utility, and intensive within-person sampling versus population-level replication.

Use pull requests to propose or revise a synthesis. Summaries should remain open to correction.
